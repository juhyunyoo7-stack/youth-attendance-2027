# 청소년부 출석부 2027

주일 출석체크, 연간 출석부, 심방 관리를 한곳에서 하는 교회 청소년부용 출석부입니다.

- **설치형 앱(PWA)**: https://juhyunyoo7-stack.github.io/youth-attendance-2027/
  휴대폰이나 PC에서 열고 "앱 설치" 또는 "홈 화면에 추가"를 누르면 앱처럼 쓸 수 있습니다. 인터넷 없이도 열리고, 자료는 그 기기 안에만 저장됩니다.
- **교사 공유판**: claude.ai 아티팩트로 배포합니다. 초대받은 선생님들이 같은 출석부에 실시간으로 함께 기록합니다.

두 판은 같은 백업 파일(.json) 형식을 쓰므로 서로 옮길 수 있습니다.

## 구조

| 경로 | 내용 |
|---|---|
| `src/app.html` | 앱 본체 (화면·로직 전부). 저장소 계층만 `MODE`에 따라 바뀝니다 |
| `build.js` | `node build.js` — 아래 산출물을 만듭니다 |
| `docs/` | 설치형 앱 (index.html, manifest, 서비스워커, 아이콘) — GitHub Pages가 여기서 배포 |
| `shared/index.html` | 교사 공유판 (claude.ai `db` 사용) |

수정할 때는 `src/app.html`을 고친 뒤 `node build.js`를 실행하고, 오프라인 캐시를 갱신하려면 `docs/sw.js`의 `VERSION`을 올립니다.

학생 개인정보는 이 저장소에 들어 있지 않습니다. 설치형은 각 기기의 브라우저에, 공유판은 claude.ai의 비공개 데이터베이스에 저장됩니다.
